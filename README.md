## Política de privacidad y seguridad

Salseo APK es una aplicación social de recetas, vídeos, chats y perfiles de usuario. La aplicación utiliza Firebase, un servicio de Google, para gestionar el registro, el inicio de sesión, los perfiles, los chats, las notificaciones internas y otros datos necesarios para el funcionamiento de la app.

Salseo puede guardar datos como el nombre de usuario, email de registro, foto o fondo de perfil, publicaciones, comentarios, favoritos, usuarios seguidos, mensajes de chat y notificaciones. Estos datos se usan únicamente para permitir el funcionamiento normal de la aplicación.

Salseo no vende datos personales, no solicita datos bancarios y no utiliza la información de los usuarios para fines ajenos a la propia aplicación.

El acceso a la cuenta se realiza mediante Firebase Authentication, incluyendo email y contraseña o inicio de sesión con Google. Los datos públicos, como nombre de usuario, perfil, comentarios, favoritos o mensajes publicados, pueden ser visibles para otros usuarios dentro de Salseo.

Las imágenes de chat pueden añadirse mediante URL pública. La aplicación no necesita Firebase Storage para subir imágenes al servidor.

El usuario puede cerrar sesión o eliminar su cuenta desde los ajustes de la aplicación. Al eliminar la cuenta, se borra el acceso del usuario y su perfil asociado, aunque algunos contenidos ya publicados de forma pública podrían permanecer visibles si forman parte de conversaciones o publicaciones generales.

Salseo aplica reglas de seguridad en Firebase para limitar el acceso a los datos y evitar modificaciones no autorizadas. Aun así, se recomienda no publicar información privada, sensible o confidencial dentro de la aplicación.

_El uso de Salseo implica aceptar esta política de privacidad y seguridad._

**En siguientes actualizaciones, al eliminar la cuenta se borrará absolutamente todo lo publicado por el usuario, para ello modificando Salseo.**
